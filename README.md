## ✦ About the Portfolio

**BM Graphics** is a creative portfolio built to showcase design
thinking, visual identity, digital projects, and a passion for memorable
online experiences. The visual direction pairs a dark interface with
vivid lime accents, strong typography, project-led storytelling, and
carefully structured sections.

The goal is simple: **make the work the hero**---with a polished
experience that feels modern, confident, and easy to explore.

## 🎬 Motion & Animation Ideas

This README uses lightweight remote SVG animations to give the
repository page some personality. For the website itself, these motion
treatments can create a more immersive experience:

  -----------------------------------------------------------------------
  Effect                              Suggested treatment
  ----------------------------------- -----------------------------------
  Hero entrance                       Staggered fade-up for headline,
                                      subtitle, and buttons

  Scroll reveals                      Subtle fade-and-rise as sections
                                      enter the viewport

  Project cards                       Image zoom, soft glow, and a small
                                      lift on hover

  Cursor details                      Restrained magnetic or spotlight
                                      effect on desktop

  Skill/service items                 Sequential reveal with short delays

  Background accents                  Slow, low-contrast gradient or
                                      particle movement

  Page transitions                    Quick fade/slide between views, if
                                      routing supports it

  Loading state                       Minimal branded loader with a
                                      smooth exit
  -----------------------------------------------------------------------

**Motion principle:** animations should feel intentional, fast, and
smooth---not distract from the work. Respect `prefers-reduced-motion`,
avoid excessive parallax, and keep mobile performance in mind.

### Suggested motion guidelines

-   Keep most transitions between **180--450 ms**.
-   Prefer `transform` and `opacity` for smoother animation.
-   Animate content when it enters view rather than animating every
    element continuously.
-   Avoid motion that blocks reading, navigation, or form submission.
-   Test on low-powered phones and with reduced-motion preferences
    enabled.

## ♿ Accessibility & Performance

A great portfolio should look impressive and remain comfortable to use.

-   Provide descriptive `alt` text for meaningful images.
-   Ensure text and buttons have sufficient contrast.
-   Make interactive elements usable with a keyboard.
-   Use visible focus states and descriptive link labels.
-   Compress images and serve appropriately sized assets.
-   Lazy-load below-the-fold images where appropriate.
-   Keep animation optional for visitors who prefer reduced motion.
